Installation

Install EngineX using your preferred package manager:

Terminal 
# Using Bun (recommended)
bun add enginex

# Using pnpm
pnpm add enginex

# Using npm
npm install enginex
Note: EngineX is optimized for Bun and requires Bun v1.0 or later.

Quick Start

Create your first EngineX server in just a few lines:

server.ts 
import { HybridApplication } from 'enginex';

const app = new HybridApplication();

// Add middleware
app.use(async (ctx, next) => {
  const start = Date.now();
  await next();
  const ms = Date.now() - start;
  console.log(`${ctx.method} ${ctx.path} - ${ms}ms`);
});

// Handle requests
app.use(async (ctx) => {
  ctx.status = 200;
  ctx.responseBody = { message: 'Hello, EngineX!' };
});

app.listen(3000, () => {
  console.log('Server running on http://localhost:3000');
});

Run your server:

bun run server.ts

Middleware

EngineX uses the same middleware pattern as Koa — the "onion model":

middleware.ts 
import { HybridApplication, cors, logger } from 'enginex';

const app = new HybridApplication();

// Built-in middleware
app.use(logger());           // Request logging
app.use(cors());             // CORS headers
app.use(errorHandler());     // Error handling

// Custom middleware
app.use(async (ctx, next) => {
  // Before request
  console.log('Request started');

  await next();  // Call next middleware

  // After response
  console.log('Request completed');
});

Available Middleware

  • logger() — Request/response logging
  • cors() — Cross-Origin Resource Sharing
  • bodyParser() — Parse JSON and form bodies
  • errorHandler() — Centralized error handling

Routing

EngineX includes a high-performance Trie-based router:

routes.ts 
import { HybridApplication, Router } from 'enginex';

const app = new HybridApplication();
const router = new Router();

// Basic routes
router.get('/', async (ctx) => {
  ctx.responseBody = { message: 'Home' };
});

// Path parameters
router.get('/users/:id', async (ctx) => {
  ctx.responseBody = { userId: ctx.params.id };
});

// Route groups
router.group('/api/v1', (r) => {
  r.get('/users', listUsers);
  r.post('/users', createUser);
  r.get('/users/:id', getUser);
});

app.use(router.routes());
app.listen(3000);

HTTP Methods

  • router.get(path, handler)
  • router.post(path, handler)
  • router.put(path, handler)
  • router.delete(path, handler)
  • router.patch(path, handler)
  • router.all(path, handler)

Context

The context object provides access to request and response:

context.ts 
app.use(async (ctx) => {
  // Request properties
  ctx.method      // 'GET', 'POST', etc.
  ctx.path        // '/users/123'
  ctx.url         // Full URL
  ctx.query       // { page: '1' }
  ctx.params      // { id: '123' }
  ctx.headers     // Request headers
  ctx.body        // Parsed request body

  // Response properties
  ctx.status = 200;
  ctx.responseBody = { data: 'value' };
  ctx.set('X-Custom-Header', 'value');

  // Methods
  ctx.get('Content-Type');    // Get request header
  ctx.set('X-Header', 'val'); // Set response header
  ctx.throw(404, 'Not found');// Throw HTTP error
  ctx.redirect('/login');     // Redirect
});
